02

Steal a Job

Competitive Multiplayer

A real-time competitive game where jobs are the contested resource. Players physically approach each other to trigger a steal — proximity detection runs server-side with magnitude checks so clients can never fake position. Every job transfer is validated and recorded. A live leaderboard re-ranks players instantly on each ownership change, and per-player cooldowns block spam stealing. Progression is DataStore-backed so rankings persist across sessions.

Proximity Magnitude Checks Server-Authoritative Transfers Per-Player Cooldowns Live Leaderboard Anti-Exploit Validation DataStore Persistence Respawn Logic
key mechanics
+Server magnitude check on steal — client position never trusted
+Job transfer runs entirely on server via RemoteEvent validation
+Cooldown tracked per-player on server — can't be bypassed by client
+Leaderboard updates on every ownership change in real time
+Job re-assigned automatically on character respawn
03

Dragon Boss Fight

Boss AI / PvE

A solo PvE fight against a 1000 HP dragon powered by a custom AI behavior loop — no PathfindingService, just a real aggro-and-pursue system built from scratch. The dragon launches fireballs on a physics arc the player can dodge, and swings a sword using sphere overlap hit detection. Players counter with a Q-key Air Blast (server-enforced 6s cooldown). All damage, hit registration, and ability gating are server-authoritative — clients only send input, never apply state.

Custom Aggro Loop Sphere Overlap Detection Physics Arc Projectile Server-Side Damage Ability Cooldown Gate Dual HP Bar UI RemoteEvent Architecture
key mechanics
+Aggro loop: dragon detects, locks, and pursues target continuously
+Fireball on a BodyVelocity arc — timing-based dodge window
+WorldRoot:GetPartsInPart() sphere overlap for melee hit detection
+Air Blast ability cooldown enforced server-side — client can't fire twice
+Tweened HP bars for both boss and player update in real time
